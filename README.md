# Отчёт по улучшению качества тестов

## Цели
* Покрытие веток (branch coverage): ≥ 70 %.
* Mutation Score: ≥ 80 %.

## Выполненные действия

1. **Анализ текущего состояния:**
   * Запущены существующие тесты (`make test`).
   * Получен исходный Mutation Score (`make mutate`).
   * Сгенерирован отчёт о покрытии (`make htmlcov`).

2. **Улучшение покрытия:**
   * Добавлены тесты для крайних случаев (нулевые значения, отрицательные числа).
   * Покрыты все ветки функций, включая обработку ошибок.
   * Протестированы разные сценарии применения купонов.
   * Проверены граничные условия (пустые списки, большие скидки).

3. **Работа с мутантами:**
   * Выявлены «выжившие» мутанты (`make results`).
   * Для каждого типа мутанта (замена операторов, изменение констант) добавлены тесты.
   * Итеративно улучшался Mutation Score до достижения цели.

4. **Проверка результатов:**
   * Подтверждено покрытие ≥ 70 % (через HTML‑отчёт).
   * Достигнут Mutation Score ≥ 80 % (`make mutate`).

## Инструменты
* `pytest` — запуск тестов.
* `pytest-cov` — измерение покрытия.
* `mutmut` — mutation testing.
* Makefile — автоматизация процессов.

## Результаты
* **Покрытие веток:** %.
* **Mutation Score:** %.
* **Выжившие мутанты:** 0 (все устранены).


* Регулярно запускать `mutmut` для поддержания высокого качества.
* Обновлять тесты при изменении логики функций.
