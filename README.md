# Отчёт по улучшению качества тестов

## Цель
Улучшить качество тестов в проекте, достигнув:
- Mutation Score ≥ 80% (с помощью `mutmut`).
- Покрытие веток ≥ 70% (с помощью `pytest-cov`).

## Выполненные действия

1. **Анализ исходного состояния**.
   - Запущены существующие тесты: `make test`.
   - Получен начальный Mutation Score: «65%».
   - Сгенерирован отчёт о покрытии: `make htmlcov`. Начальное покрытие веток: «55%».
